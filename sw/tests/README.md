# Directed test programs

Each program is self-checking: exit code 0 is a pass, any other value is the
number of the check that failed.

| Program | Covers |
| --- | --- |
| `arith.S` | Add, subtract, logic, comparisons, `lui`, `auipc`, wide constants, the 32-bit operations |
| `shifts.S` | All shifts, 64-bit and 32-bit, shift-amount masking |
| `branch.S` | All six branches both ways, `jal`, `jalr`, loops, recursion with a stack |
| `mem.S` | Every load and store width, sign and zero extension, byte order |
| `traps.S` | Each exception's cause, `mepc` and `mtval`; `mret`; CSR instructions |
| `precise.S` | That exceptions are precise: nothing behind a faulting instruction takes effect |
| `hazards.S` | One check per forwarding, stall and squash path of a pipeline |
| `predict.S` | Control flow that a branch predictor gets wrong |
| `ooo.S` | Cases that only matter out of order: loads behind late stores, renamed registers, wrong-path work |
| `pairs.S` | Cases that only matter two instructions at a time |
| `wpolicy.S` | Stores that have to survive the cache's write policy and write buffer |
| `hier.S` | Dirty lines that have to survive a cache hierarchy, inclusion and a victim buffer |
| `sort.S`, `fib.S` | Small kernels: data-dependent branches, load/store traffic, console output |

`pairs.S`, `wpolicy.S` and `hier.S` are generated by the `gen_*.py` script of
the same name; edit the script and run it. A unit test checks that each file
is up to date.
